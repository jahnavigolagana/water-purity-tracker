About Mini-Project

Academic Mini-Project Integration: Engineering Chemistry + IT Workshop + Python AI

Project Objectives & Problem Statement

Hostels accommodate thousands of students where water quality directly affects health. Manual monitoring often lacks consistent logging, delayed detection of acidic/alkaline spikes, high total dissolved solids (TDS), or pathogen turbidity.

The Solution: "Water Purity Tracker for Hostel" bridges fundamental Engineering Chemistry titration standards with modern Python AI rule algorithms, Web Development, and CSV persistence to digitize, analyze, predict, and automate water treatment recommendations.

Project Workflow Pipeline
Water Test Input → Parameter Analysis → Purity Score Calculation → Python Rule Engine → AI Recommendation → CSV Storage → Dashboard Updates → Reports & Analytics
Integrated Academic Disciplines
Engineering Chemistry
Water hardness, pH scale evaluation, TDS ppm measurement, and Turbidity nephelometric standards (IS 10500 / WHO limits).
Python Rule Engine (AI Layer)
Intelligent condition-action rule sets mapping chemical deviations to precise purification treatments (RO, Neutralization, UV).
CSV File Handling
Mandatory structured data logging in water_readings.csv with real-time filtering, search, and export capability.
IT Workshop & Web Dev
Full-stack Flask architecture, Chart.js visualizations, responsive Glassmorphism UI, and RESTful APIs.
